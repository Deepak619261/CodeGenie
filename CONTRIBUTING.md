# Contributing to NexusCode

Thank you for your interest in contributing to NexusCode! We welcome contributions from the community to help make this cost-aware coding agent even better.

## How to Contribute

### Reporting Bugs
If you find a bug, please create an issue on GitHub with a detailed description of the problem and steps to reproduce it.

### Suggesting Enhancements
We welcome ideas for new features or improvements! Open an issue to discuss your suggestions.

### Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or bugfix.
3. Make your changes and ensure the code follows the existing style.
4. Submit a pull request with a clear description of your changes.

## Development Setup

1. Install [VS Code](https://code.visualstudio.com/).
2. Install [Node.js](https://nodejs.org/).
3. Clone this repository.
4. Run `npm install` to install dependencies.
5. Run `npm run compile` to build the extension.
6. Press `F5` in VS Code to run the extension in a new Extension Development Host window.

Wait for the NexusCode Python backend to be running on `ws://127.0.0.1:8765/ws` for full functionality.
